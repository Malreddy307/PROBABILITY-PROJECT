Learn the basics

How to read this dashboard
  • λ (failure rate): failures expected per unit of time. Bigger means less reliable.
  • MTTF: the average lifetime, equal to 1/λ.
  • R(t): the chance a part is still working at time t.
  • Model fit check: green means your data behaves like an exponential model.

The formulas, in plain words

  • Failure density: f(t) = λe-λt
  • Reliability (still working at t): R(t) = e-λt
  • Average lifetime: MTTF = 1/λ, and median life is ln 2 / λ
  • Series system (all must work): Rn. Parallel system (one is enough): 1 - (1 - R)n
  • The failure rate never changes, so a used part is as likely to survive the next hour as a new one (memoryless).
